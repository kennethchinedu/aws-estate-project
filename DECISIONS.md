## Other decisions

1. **5 accounts, no Account Factory vending.** The Organizations account quota was not raised. payments-dev and payments-prod are enrolled, not vended; analytics-prod and sandbox do not exist. payments-dev stands in for the consumer side of cross-account tests. Upgrade path: raise the quota, then vend accounts with Account Factory for Terraform (AFT).
2. **`hexpayr1` IAM user kept.** An admin key on the management account, used by another system. Humans and Terraform use IAM Identity Center (SSO profile, MFA, temporary credentials), proven by a clean plan on all 5 stacks. This is an exception to "no IAM users with long-lived keys". Plan: scoped credentials for that system, then deactivate, then delete.
3. **Estate lives in an existing organization** alongside other workloads. Teardown removes this estate's resources only.
4. **Detection in eu-west-2 only.** For cost. eu-west-1 is a governed region (region deny allows it) but has no GuardDuty or Security Hub. Trigger: before any workload runs there, extend with `for_each` over regions and `moved` blocks.
5. **Proactive controls do not see Terraform.** They are CloudFormation hooks, and this estate is deployed with Terraform, so they only catch CloudFormation deployments. Kept as defence in depth; enforcement comes from SCPs and detective rules.
6. **GuardDuty Malware Protection for EC2 off.** No EC2 workloads yet. Enabling it needs the management account to allow the delegated administrator to create the Malware Protection service-linked role in members. Revisit when instances run in payments-prod.
7. **`AWSControlTowerExecution` used as Terraform's cross-account role** (detection stack into Audit). It is admin and exempt from the CloudTrail and log-deletion SCPs. Plan: a dedicated, narrower deployer role (the OIDC deployment chain).
8. **SSE-S3 on the Terraform state bucket**, not a KMS key. Simpler and free. Revisit when decrypt access needs to be logged and restricted by key policy.
9. **Sandbox OU not registered.** It is empty, so there is nothing to govern yet, but it has no Control Tower controls and no region deny. Known gap: the brief asks for every OU except Suspended to be registered.
10. **Control Tower decommission** was blocked by `OptInRequired` in 2 reactivated accounts; their stack instances were removed with `RetainStacks`, then the delete was retried.
